# 시뮬레이션 설문 데이터 코드북

대상 논문: 이선빈·김지현(2025), 「학부 유학생의 한국어 쓰기 효능감·호감도·상위인지 전략 사용 양상 연구」, 『작문연구』 65, 7-41.

이 폴더의 데이터는 논문에 보고된 기술통계(표 1, 3, 4, 5, 6, 7, 8, 9)를 재현하도록 **가상으로 생성**한 것이며, 실제 응답자 자료가 아니다.

## 파일

| 파일 | 내용 |
|---|---|

| `survey_analysis.ipynb` | 기초 통계 노트북: 응답자별 M/SD, 문항 평균·분산·산포도·KDE, 공분산·상관, Cronbach's α (수식 vs pingouin) |

### 5점 리커트 문항 (1 = 전혀 아니다 … 5 = 매우 그렇다)

| 열 | 척도 | 하위 요인 (논문 표 3 문항 번호) |
|---|---|---|
| `SE01`~`SE05` | 쓰기 효능감 | 발상 (1~5) |
| `SE06`~`SE10` | 쓰기 효능감 | 규칙 (6~10) |
| `SE11`~`SE16` | 쓰기 효능감 | 자기 조절 (11~16) |
| `LW17`, `LW19` | 쓰기 호감도 | 긍정적 태도 (17, 19) |
| `LW18`, `LW20` | 쓰기 호감도 | 부정적 태도 (18, 20) — 역채점하지 않은 원점수 |

## 생성 원리 요약

1. 응답자마다 8개 잠재 요인(발상, 규칙, 자기조절, 긍정호감, 부정호감, 계획, 작성, 검토)을 논문 표 7의 상관 구조를 갖는 다변량 정규분포에서 뽑고, TOPIK 급수별 평균 차이(표 8, 9)를 더한다.
2. 문항 점수 = 문항 평균 + 부하량 × 잠재 요인 + 문항 고유 오차 → 반올림 후 1~5로 절단.
3. 반올림·절단으로 생기는 왜곡은, 난수를 고정한 채 파라미터(문항 평균, 요인 분산, 오차 분산, 잠재 상관, 집단 오프셋)를 반복 보정하여 논문 수치에 맞춘다. 반복 중 오차가 가장 작은 파라미터를 최종 채택한다.

## 논문 수치와의 일치 정도 및 알아둘 점

- 표 1·4 빈도: 완전 일치. 표 5 하위 척도 M·SD: 소수 둘째 자리까지 일치. 표 3 Cronbach's α: 오차 ≤ 0.003. 표 6 문항 M·SD: 오차 ≤ 0.02 (아래 예외 제외). 표 7 상관: 최대 절대 오차 0.026, 평균 0.008.
- **MC26(표 6, M 3.76, SD 0.40)**: 1~5 정수 응답에서 평균이 3.76이면 도달 가능한 최소 SD는 약 0.43이므로(3점·4점만 응답), 논문의 0.40은 정수 자료로는 재현이 불가능하다. 시뮬레이션은 최소값(0.43)에 맞추었다.
- **표 8·9의 급수별 M·SD**: 생성 시 급수별 평균과 SD 를 모두 목표로 보정하여, 발상·규칙·자기조절·부정 호감도·계획·작성 여섯 요인은 논문 값과 ±0.01 이내로 일치하고 일원분산분석 F 도 같은 결론을 준다(검증 보고서 참조).
- **표 8의 '긍정 호감도'와 표 9의 '검토 전략'**: 세 급수 집단의 M·SD(3.41/3.89/3.39, SD 1.04/.72/.93; 3.89/3.85/4.31, SD .99/.67/.80)를 그대로 두면 집단 내 분산 + 집단 간 분산만으로 전체 SD 가 각각 ≥0.92, ≥0.95 가 되어 표 5의 0.87, 0.74 를 넘는다('없음' 집단의 분산이 0이어도). 즉 논문의 두 행은 표 5와 산술적으로 양립하지 않으며, 어느 한쪽을 골라야 한다. 기본 파일 `survey_data.csv`(`--priority table5`)는 표 5를 우선하고 이 두 척도의 집단 차이(M·SD)를 방향만 유지한 채 35 % 로 축소한다(`GROUP_SHRINK`). `survey_data_table89.csv`(`--priority table89`)는 표 8·9를 우선해 두 척도의 급수별 M·SD 와 검토 전략의 F 를 논문대로 맞추는 대신 표 5의 전체 SD 가 어긋난다(긍정 .94, 검토 .97). 긍정 호감도는 논문의 F=1.827 자체가 표에 적힌 M·SD 와 맞지 않아(계산하면 F≈4.5) 어느 쪽으로도 F 는 재현되지 않는다.
- 표 10의 회귀계수는 목표로 삼지 않았다(종속변수 정의가 논문에 없음).
- 문항별 SD(표 6의 6개 문항 외)는 논문에 없으므로, 하위 척도 SD와 α로부터 유도된 값이다(예: 계획·검토 전략 문항은 α가 상대적으로 낮아 문항 SD가 1.1~1.2로 커진다).
